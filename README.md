This is a small program that writes one short text — a dad joke — for make.fun's bounty `u-mfnakmal-dad-joke-showdown-1d2ce3e5`. It uses only the Python 3.13 standard library, makes no network calls, and writes the joke to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating that folder if needed.
